# 카카오톡으로 청첩장 보내기

원빈님 계획대로 **① 카톡으로 링크 보내기**, **② 프로필 배경에 링크 걸어두기** 두 가지를 다루겠습니다.
공통으로 먼저 배포가 되어 있어야 합니다(README.md 의 "배포" 참고).

---

## 0. 배포 직후 반드시 할 일 — 주소 3곳 바꾸기

`index.html` 을 열고 위쪽에서 `여기에-배포주소` 를 찾아 **실제 주소로 바꾸세요.** 두 줄입니다.

```html
<meta property="og:url"   content="https://오원빈경란.netlify.app/">
<meta property="og:image" content="https://오원빈경란.netlify.app/assets/images/share.jpg">
```

**이게 왜 중요한가**
카카오톡은 링크를 받으면 그 페이지의 `og:` 태그를 읽어서 미리보기 카드를 만듭니다.
이때 카카오톡은 **자바스크립트를 실행하지 않습니다.** 그래서 이 값은 반드시 HTML에 직접,
그리고 `https://` 로 시작하는 **전체 주소**로 적혀 있어야 합니다.
`assets/images/share.jpg` 같은 상대경로를 넣으면 이미지가 안 뜹니다.

> `share.jpg` 는 `사진넣기.bat` 이 표지 사진에서 자동으로 만들어 줍니다(1200×630).

## 1. 카톡으로 링크 보내기

### 방법 A — 그냥 주소 붙여넣기 (가장 간단)

카톡 대화창에 `https://오원빈경란.netlify.app` 을 붙여넣고 보내면 됩니다.
위의 og 태그가 제대로 들어가 있으면 **사진 + 제목 + 날짜/장소**가 담긴 카드로 예쁘게 나갑니다.

### 방법 B — 청첩장 안의 "청첩장 공유하기" 버튼

하객이 다른 사람에게 전달할 때 쓰는 버튼입니다. 지금은 **주소 복사**로 동작합니다.
카톡 전용 공유 카드로 띄우고 싶다면:

1. <https://developers.kakao.com> 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
2. 만든 앱 → **앱 키 → JavaScript 키** 복사
3. `assets/js/config.js` 맨 아래 `kakao: { appKey: '' }` 안에 붙여넣기
4. 같은 페이지의 **플랫폼 → Web → 사이트 도메인 등록** 에 배포 주소 입력
   (예: `https://오원빈경란.netlify.app` — 끝에 `/` 없이)
5. **카카오 로그인** 은 켤 필요 없습니다. 메시지 공유만 쓰는 거라 그대로 두세요.

앱 키를 안 넣으면 자동으로 주소 복사로 동작하니, 굳이 안 하셔도 됩니다.

### 미리보기가 예전 내용으로 뜰 때

카카오톡은 한 번 읽은 링크의 미리보기를 **캐시에 저장해 두고 재사용**합니다.
og 태그를 고쳤는데 예전 이미지가 계속 나온다면:

<https://developers.kakao.com/tool/clear/og> 에서 주소를 넣고 **캐시 초기화**를 누르세요.
(카카오 계정 로그인만 하면 되고, 앱 등록은 필요 없습니다.)

## 2. 프로필 배경에 링크 걸어두기

카카오톡 **프로필 배경 자체에는 링크를 넣을 수 없습니다.** 대신 이렇게들 합니다.

### 방법 A — 프로필 소개글(상태메시지)에 주소 적기 (가장 많이 쓰는 방법)

카카오톡 → 내 프로필 → 프로필 편집 → 소개글에 주소를 그대로 적습니다.

```
2026.11.22 오원빈♥김경란
https://오원빈경란.netlify.app
```

친구가 프로필을 눌러 소개글의 주소를 탭하면 열립니다.
**주소가 짧고 읽기 쉬울수록 좋습니다.** 배포할 때 사이트 이름을 이해하기 쉽게 정하세요
(Netlify는 무료로 이름 변경이 됩니다: Site settings → Change site name).

### 방법 B — 프로필 배경 이미지에 주소를 인쇄해 넣기

배경 이미지 자체에 `오원빈경란.netlify.app` 글자를 넣어두면, 소개글과 함께 보여서
"이걸 눌러야 하는구나"가 더 잘 전달됩니다. 이미지는 눌러도 안 열리니
**반드시 소개글에도 주소를 같이 적어야** 합니다.

### 방법 C — 카카오톡 멀티프로필

친구 그룹별로 다른 프로필을 보여줄 수 있습니다.
회사 사람들에게는 청첩장 프로필을, 다른 그룹에는 평소 프로필을 보이게 할 수 있습니다.

## 3. 보내기 전 점검

- [ ] `index.html` 의 `여기에-배포주소` 두 곳을 실제 주소로 바꿨다
- [ ] `assets/images/share.jpg` 가 존재한다 (`사진넣기.bat` 실행하면 자동 생성)
- [ ] 배포 주소를 **본인 카톡(나와의 채팅)에 먼저 보내서** 미리보기 카드를 확인했다
- [ ] 카드에 사진·제목·날짜가 제대로 나온다
- [ ] 안드로이드와 아이폰 양쪽에서 한 번씩 열어봤다
- [ ] 계좌번호·전화번호가 공개돼도 괜찮은지 다시 확인했다 (링크를 아는 사람은 누구나 봅니다)

## 4. 알아두실 점

- **검색엔진 차단이 걸려 있습니다.** `index.html` 에 `noindex` 를 넣어놔서 네이버·구글 검색에는
  안 잡힙니다. 카카오톡 미리보기는 이것과 무관하게 정상 동작합니다.
- **예식이 끝나면** 링크를 내리거나 구글 시트(참석 명단·방명록)를 정리하시는 걸 권합니다.
  계좌번호와 전화번호가 계속 공개된 상태로 남습니다.
