# 방명록 · 참석 여부 저장소 만들기 (구글 시트)

서버 없이 구글 시트에 저장합니다. 무료이고, 하객은 구글 로그인을 하지 않아도 됩니다.
처음 한 번만 10분 정도 걸립니다.

## 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 이름을 `청첩장 방명록` 정도로 바꿉니다.
   (시트 탭은 만들 필요 없습니다. `방명록`, `참석여부` 탭은 첫 저장 때 자동 생성됩니다.)

## 2. 스크립트 붙여넣기

1. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 편집기에 있던 `function myFunction() {}` 를 **전부 지웁니다.**
3. 이 폴더의 `Code.gs` 내용을 **전부 복사해서 붙여넣고** 저장(Ctrl+S)합니다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. 아래처럼 설정합니다.
   - 설명: `청첩장`
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 이걸 꼭 바꿔야 하객이 쓸 수 있습니다
4. **배포** → 권한 요청이 뜨면 승인합니다.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동** 을 누릅니다.
   본인이 만든 스크립트라 정상입니다.
5. 마지막에 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/AKfy....../exec` 형태입니다.

## 4. 청첩장에 연결

`assets/js/config.js` 를 열고 `gasUrl` 에 붙여넣습니다.

```js
gasUrl: 'https://script.google.com/macros/s/AKfy....../exec',
```

저장하고 청첩장을 새로고침하면 방명록과 참석 여부가 동작합니다.

## 5. (선택) 관리자 비밀번호

하객이 비밀번호를 잊어버린 방명록도 지울 수 있게 하려면:

Apps Script 편집기 → 왼쪽 **프로젝트 설정(톱니바퀴)** → **스크립트 속성** →
속성 `ADMIN_PW`, 값에 원하는 비밀번호를 넣고 저장하세요.
삭제할 때 그 비밀번호를 넣으면 어떤 글이든 지울 수 있습니다.

---

## 확인하는 방법

- **참석 명단**: 구글 시트의 `참석여부` 탭에 제출 순서대로 쌓입니다.
- **방명록**: `방명록` 탭. 삭제된 글은 지워지지 않고 `삭제됨` 열이 `TRUE` 로 바뀝니다.
  (실수로 지웠을 때 되살릴 수 있게 남겨둡니다. `FALSE` 로 고치면 다시 보입니다.)

## 스크립트를 고친 뒤에는

`Code.gs` 를 수정하면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 눌러야
바뀐 내용이 실제로 적용됩니다. URL 은 그대로 유지됩니다.

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 저장이 안 되고 "전송에 실패했습니다" | 3번의 **액세스 권한: 모든 사용자** 설정을 놓쳤을 가능성이 큽니다 |
| 방명록이 "준비 중" 으로만 보임 | `config.js` 의 `gasUrl` 이 비어 있습니다 |
| 스크립트를 고쳤는데 그대로 | 위 "스크립트를 고친 뒤에는" 참고 — 새 버전으로 다시 배포해야 합니다 |
