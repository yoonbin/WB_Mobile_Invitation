# 배경음악 넣는 곳

여기에 mp3 파일을 넣고 `assets/js/config.js` 의 `bgm.file` 에 파일명만 적으면 됩니다.

```js
bgm: { file: 'wedding.mp3', autoplay: false }
```

- 파일을 넣지 않으면 재생 버튼이 아예 표시되지 않습니다.
- 3~5MB 이하를 권합니다. 하객 대부분이 휴대폰 데이터로 열어봅니다.
- 자동재생(`autoplay: true`)은 iOS·안드로이드 브라우저가 대부분 막습니다.
  버튼을 눌러야 재생되는 게 정상입니다.
- 상업 음원은 저작권 확인이 필요합니다.
