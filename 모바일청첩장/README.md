빌드 도구 없이 HTML/CSS/JS 파일만으로 동작합니다. 폴더째 올리면 그대로 청첩장이 됩니다.

```
index.html                  화면 구조 + 카카오톡 미리보기(og) 태그

assets/css/style.css        디자인
assets/js/config.js         ★ 내용을 바꾸는 곳 — 여기만 고치면 됩니다
assets/js/main.js           동작 (달력, 갤러리, 복사, 방명록 등)
assets/images/              사진을 넣는 곳 (README.md 참고)
assets/audio/               배경음악 mp3 (선택)
tools/import_photos.py      사진넣기.bat 이 실제로 실행하는 스크립트

```

## 사진 채우기

**`사진넣기.bat` 위로 사진이 든 폴더를 끌어다 놓으면 끝입니다.**
이름 변경·크기 축소·위치정보 제거·`config.js` 수정까지 자동으로 됩니다.
첫 번째 사진이 표지가 됩니다. 순서는 원본 파일명 앞에 `01_`, `02_` 를 붙여 정하세요.

자세한 내용과 아이폰 HEIC 사진 처리법은 `assets/images/README.md` 를 보세요.

## 내용 바꾸기

`assets/js/config.js` 하나만 열면 됩니다. 따옴표 안 글자만 바꾸고 저장 후 새로고침하세요.

- 값을 `''` (빈 문자열)로 두면 그 항목은 화면에서 자동으로 숨겨집니다.
- 돌아가신 부모님은 이름 앞에 직접 `故 ` 를 붙이면 됩니다. 예: `name: '故 오성택'`
- 인사말처럼 여러 줄인 항목은 배열의 한 칸이 한 줄입니다. `''` 는 한 줄 띄기입니다.

## 미리보기 (내 PC에서)

`index.html` 을 더블클릭해도 대부분 보이지만, 브라우저 보안 정책 때문에 일부 기능이 막힙니다.
아래처럼 간단한 서버를 띄우고 <http://localhost:5173> 으로 여는 걸 권합니다.

```bash
python -m http.server 5173
```

## 배포 (하객에게 링크 보내기)

### 방법 1 · Netlify Drop — 가장 쉬움, 회원가입 없이 가능

1. <https://app.netlify.com/drop> 접속
2. 이 폴더를 통째로 창에 끌어다 놓기
3. 바로 나오는 `https://xxxx.netlify.app` 주소가 청첩장 링크

### 방법 2 · GitHub Pages — 무료, 주소를 계속 쓰기 좋음

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 올립니다
2. 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 저장
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다

내용을 고칠 때마다 파일을 다시 올리면 링크는 그대로 두고 내용만 바뀝니다.

## 카카오톡 공유 · 프로필 배경 링크

**`카톡공유-안내.md`** 에 따로 정리해 두었습니다.

핵심만 먼저 말하면 — 배포한 뒤 `index.html` 위쪽의 `여기에-배포주소` 두 곳을 실제 주소로
바꿔야 카톡 미리보기 카드에 사진과 문구가 뜹니다. 카카오톡은 자바스크립트를 실행하지 않아서
`config.js` 에 적은 값은 미리보기에 반영되지 않습니다.

## 배경음악 (선택)

`assets/audio/` 에 mp3를 넣고 `config.js` 의 `bgm.file` 에 파일명을 적으면
오른쪽 위에 재생 버튼이 생깁니다.

- 자동재생은 대부분의 휴대폰에서 차단됩니다. 하객이 버튼을 눌러야 재생됩니다.
- 상업용 음원은 저작권 확인이 필요합니다. 저작권 걱정 없는 음원을 쓰세요.

## 알아두면 좋은 것

- **디자인**: 제주 늦가을 유리온실을 모티프로 잡았습니다. 아치형 표지 사진 위의 격자선은
  온실 창살입니다. 색은 `style.css` 맨 위 `:root` 에 모여 있어 거기서 한 번에 바꿀 수 있습니다.
- **개인정보**: 배포하면 누구나 링크로 볼 수 있습니다. 계좌번호와 전화번호가 공개된다는 뜻입니다.
  링크를 아는 사람만 보긴 하지만, 검색엔진에 걸리지 않게 하려면
  `index.html` 의 `<head>` 에 `<meta name="robots" content="noindex">` 를 추가하세요.
- **참석 명단**은 구글 시트에 쌓입니다. 예식이 끝나면 시트와 배포를 정리하는 걸 권합니다.
