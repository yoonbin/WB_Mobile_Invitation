# 사진 넣는 곳

## 가장 쉬운 방법 — 끌어다 놓기

프로젝트 맨 위 폴더의 **`사진넣기.bat`** 위로 **사진이 든 폴더를 끌어다 놓으세요.**

그러면 알아서 다 해줍니다.

- 세로로 찍은 사진 똑바로 세우기 (EXIF 회전 반영)
- **위치정보(GPS) 등 사진에 박힌 개인정보 전부 제거** ← 공개 페이지라 중요합니다
- 휴대폰에서 빨리 열리는 크기로 축소
- `cover.jpg` / `gallery-01.jpg` / `gallery-02.jpg` … 로 이름 변경
- 카카오톡 미리보기용 `share.jpg` 생성
- `config.js` 의 갤러리 목록을 실제 장수에 맞게 수정
- `index.html` 의 캐시 번호를 올려서 하객 휴대폰이 옛 사진을 계속 보여주지 않게 처리

**첫 번째 사진이 표지가 됩니다.** 순서를 정하고 싶으면 원본 파일 이름 앞에
`01_`, `02_`, `03_` 을 붙이세요. 이름 순서대로 들어갑니다.

사진을 다시 고르고 싶으면 그냥 다시 끌어다 놓으면 됩니다. 이전 사진은 지워지고 새로 채워집니다.

### 아이폰 사진(HEIC)이라면

아이폰 기본 설정으로 찍은 사진은 `.HEIC` 형식이라 이 도구가 읽지 못합니다. 셋 중 하나로 해결하세요.

1. **아이폰에서 카카오톡이나 메일로 PC에 보내기** — 보내는 과정에서 대개 JPG로 바뀝니다 (가장 간단)
2. 아이폰 **설정 → 카메라 → 포맷 → "높은 호환성"** 으로 바꾸고 다시 촬영
3. PC에서 `pip install pillow-heif` 를 실행한 뒤 도구를 다시 실행

도구가 HEIC를 발견하면 안내 메시지를 띄우니, 모르고 지나칠 일은 없습니다.

## 직접 넣고 싶다면

이 폴더에 아래 이름 그대로 넣어도 됩니다. 파일이 없으면 "사진 준비 중" 자리표시 이미지가 뜹니다(오류 아님).

| 파일명 | 쓰이는 곳 | 권장 크기 |
|---|---|---|
| `cover.jpg` | 표지 아치 사진 | 1000 × 1400 px (세로) |
| `gallery-01.jpg` ~ | 갤러리 | 긴 변 1400 px |
| `share.jpg` | 카카오톡 링크 미리보기 | **1200 × 630 px 고정** |
| `map.jpg` | 오시는 길 약도 (선택) | 1000 × 750 px |

- **파일 이름은 소문자, 확장자는 `.jpg`.** `map.png` 는 인식하지 않습니다.
- 직접 넣었다면 `config.js` 의 `gallery.images` 목록도 장수에 맞게 고쳐야 합니다.
- 사진 한 장 **500KB 이하**를 권합니다. 9장이 각 3MB면 하객이 27MB를 내려받습니다.

## 사진 고를 때

- **표지 사진은 위쪽이 아치(둥근 모양)로 잘립니다.** 인물 머리 위에 여백이 조금 있는 사진을 고르세요.
- **갤러리는 정사각형으로 잘립니다.** 인물이 화면 가장자리에 치우친 사진은 잘려 나갑니다.
- `share.jpg` 는 세로 사진을 가로로 자른 것이라 얼굴이 어색할 수 있습니다.
  카톡 미리보기를 확인해 보고 이상하면 1200×630 이미지를 직접 만들어 교체하세요.

## 약도(map.jpg)

네이버지도·카카오맵에서 예식장 위치를 띄우고 화면을 캡처해 `map.jpg` 로 저장하면 됩니다.
지도 캡처 이미지를 개인 청첩장에 쓰는 것은 각 서비스 이용약관을 한 번 확인해 주세요.
약도가 없어도 **티맵 / 카카오내비 / 네이버지도** 버튼은 그대로 동작합니다.
